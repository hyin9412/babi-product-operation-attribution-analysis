## 实现约定
- 交互说明的RocketMQ与Bytegraph模型预览均复用schemeThreeStyle及真实FormulaCanvas布局，全屏同步；切换模型只替换数据。
- 实际模型示例章节标题为“指标公式拓扑图 - 按实际模型的示例”，移除标题下方说明段落；RocketMQ模型选择旁显示源力Tag“含函数节点”。
- “含函数节点”Tag位于RocketMQ下拉选项内部，紧邻模型名称；选中回填沿用同一标签结构，框内保留Tag，Bytegraph不展示该Tag。
- “打开拓扑图样式 Playground →”入口移至实际模型示例章节标题右侧，同一行对齐，新标签页打开；模型预览iframe不再重复显示入口。
- 模型示例与月度/季度/年度目标勾选项同一行、垂直居中；移除“目标选择”可见标签和外框，窄屏自然换行，保留分组可访问名称。
- 节点Hover截图置入规则表首列：1–8合并8行，包含常规指标与多行数据图；函数9单独一行，括号/计算式子/常量10–12合并3行。截图使用红色编号与右侧各条规则对应；窄屏通过表格内部横向滚动查看。
- 节点Hover表格前两列（截图标注、节点/区域）固定，包含表头与合并图片单元格；仅后续规则列随横向滚动移动。前两列宽度按表格可见区域自适应，保留后续列可见空间。
- 方案三节点展开/收起按钮Hover时，仅箭头着色为rgb(var(--primary-5))；圆形背景、边框、尺寸与连接位置不变，移出恢复原图标。
- 拓扑画布触控板/滚轮缩放按deltaY幅度连续计算，系数0.003；同帧合并事件，累计幅度限30px，单帧放大至多约9.4%。按用户反馈提升小幅手势灵敏度至前版约2倍。零垂直滚动不缩放，兼容像素/行/页模式；保持指针锚点与缩放上下限，原放大/缩小按钮步长保持不变。
- 展开后的直接下级表达式按可见节点外框的左右边界中心与父指标中心对齐；子树宽度仍用于空间预留，按其实际中心放置上层指标，避免不等宽分支展开后发生水平偏移。
- 方案三指标不渲染状态Tag，也不提供开启入口；旧配置开启状态Tag时，方案三仍不展示。
- 节点Hover规则表左侧展示真实方案三节点截图，使用红色框线与编号1–12对应右侧各行；同类区域共用合并图片单元格，点击图片可查看原图。移除状态Tag截图与规则条目。截图源为实际组件DOM，生成脚本为scripts/generate-topology-hover-screenshots.py。
- 交互说明增加“节点 Hover 与光标”规则表，覆盖指标各区域、单指标/公式函数、括号、运算符和常量；区分提示触发条件、pointer/default及实际点击行为，以当前组件实现为准。
- PlaygroundStyle.metric增加classic/inset形态，function/expression形态增加inset枚举；保存/导入/导出兼容。
- 指标增加公式+数值白色内容包装层，classic使用display:contents保留原布局；inset专用CSS作用域设置标题、彩色细边和白色层。

- 共享布局记录每个节点的尺寸、内容原点、内部指标对齐基准。括号行使用可见卡片高度居中；公式函数行按内部指标基准放置直接节点、嵌套容器与运算符。

## 整行对齐补充
- 所有同一展开层级的指标顶对齐，统一到该行最深嵌套内的指标基准；单层嵌套同样传递内部指标基准。
- 计算式子使用同类对齐基准；最深层无计算式子时，沿嵌套向外使用存在计算式子的层级。常量保持与运算符居中。
- 同一行由多个上层指标展开时，先收集该行全部子公式，统一采用最深嵌套基准，再放置每个子公式；展开或收起后重新计算。
- 容器内部布局、画布递归测量、展开锚点、横向连接锚点共享同一套对齐几何。
- 嵌套对齐示例补充：多个上层指标分别展开双层、单层和普通公式，以及最深层没有计算式子的情况。
- 整行验证通过：同层所有指标顶边差值0，全部运算符可见圆形顶边差值小于0.03px；覆盖五个上层指标同时展开、最深层无运算符、逐个收起和对比联动。生产构建及生产页面验证通过，前两方案回归通过。
