# 拓扑指标偏差口径

## 页面架构与规范映射
- 页面框架：现有透明化分析拓扑看板，匹配 Dashboard 页面框架。
- 模块：现有 MetricTopologyNode 的目标偏差行；规范没有专门的拓扑模块，沿用项目组件。
- 组件：复用商品收支 IncomeMetricCard 导出的 FormulaValue，以及 AnalysisPopover 封装的源力 Popover。
- 核心功能：偏差数值增加下划线，悬停展示口径与真实数值代入公式。
- 交互闭环：hover 展开、移出关闭、关闭后卸载；缺失数据或相对偏差目标为零时说明无法计算。

## 模块定义与公式
- 月度：月度偏差 =（当月实际值 - 月度目标值）/ |月度目标值| × 100%。
- 季度：季度偏差 =（当月实际值 - 季度目标值）/ |季度目标值| × 100%。
- 年度比率类：年度目标偏差 = 月度实际值 - 年度目标值；百分比相减的结果以 pp 展示，目标为零仍可计算。
- 年度其他类别：年度目标偏差 =（当月实际值 - 年度目标值）/ |年度目标值| × 100%。
- 代入原始数值，携带指标单位；比率值转换成百分比，与节点展示口径一致。

## 样式与实现约束
- 复用商品收支虚线下划线、help 光标和弹层样式：320px 宽，8px 12px 内边距，12px 字号，20px 行高，视口内自适应。
- 延续节点偏差已有颜色，复用现有指标类型判定。
- 公式仅绑定偏差数值，目标选择继续控制对应行的显示。
- 共用渲染器覆盖主页面、拓扑预览及函数内指标节点。
- 校验：构建通过，并在预览中验证月度、季度、年度两种公式与实际 hover 弹层。
