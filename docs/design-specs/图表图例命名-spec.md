# 图表图例命名

- 沿用 Dashboard、AnalysisChart 与现有分组及配色。
- 计费项内部按已有维度顺序使用 `|` 拼接，不带空格；计费项与指标之间使用 `, `。
- 示例：`bytegraph.cpu|cn|cn-east-1, Abase`。
- TOS 保留“计费单元、大区”维度，示例：`Storage|cn, 对象存储资源`。
- 收支明细实际值、月度目标、季度目标使用同一计费项前缀；成本合计和成本商品也按此格式显示。
- 单价趋势保留各周期的指标名称，年度为累计测算单价、目标单价、累计偏差幅度。
- 仅含独立指标或类别的图例保留原名，不补充不存在的计费项维度。
- 图例、tooltip 及配色/虚线映射统一使用格式化后的系列名称。
- 图例悬停操作提示仅显示“点击排除展示”或隐藏后的“点击恢复展示”，不带 Label 前缀。
