# 收支明细目标提示

## 页面整体架构
- 命中 Dashboard 框架，改动范围为收支分析 Tab 内各资源类别的收支明细表格。
- 沿用现有页面布局、分组表头、排序、筛选、横向滚动和总计行。

## 模块与组件映射
- 表格模块：沿用 SourceTable 与 SourceTableSummary，数值右对齐。
- 提示组件：复用商品收支卡片的 FormulaValue、AnalysisPopover 和 income-metric-formula 样式。
- 数值使用虚线下划线，hover 展示白色带箭头的 Popover；宽度 320px、字号 12px、行高 20px，公式可换行。
- 表格内虚线颜色使用 `@color-text-3` 对应的 CSS 变量 `var(--color-text-3)`。

## 核心功能与交互闭环
- 月度偏差 =（当月实际值 - 月度目标值）/ |月度目标值| × 100%。
- 季度偏差 =（当月实际值 - 季度目标值）/ |季度目标值| × 100%。
- 利润率年度目标累计偏差 = 1 月至当前账期累计实际值 - 年度目标值；结果单位 pp。
- 收入、成本、利润年度目标累计占比 = 1 月至当前账期累计实际值 / 年度目标值 × 100%。
- 公式代入当前行原始数值，金额使用元、利润率使用 %；总计行使用汇总实际值及目标值。
- 缺失数值不添加下划线；除法目标为 0 时不可计算，利润率年度相减允许目标为 0。
- 全局目标筛选控制对应列显示，局部筛选后公式与数值一起更新。

## 验收约束
- 复用组件真实 API：content、trigger="hover"、unmountOnExit。
- 下划线与浮层样式和商品收支卡片一致。
- 分组覆盖成本利润率、收入、成本、利润；覆盖明细行与总计行。
- 核对公式结果与显示数值一致，缺失值无 NaN / Infinity。
