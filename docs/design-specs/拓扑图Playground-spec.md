# 拓扑图 Playground

## 页面整体架构
- 独立入口 `/topology-playground.html`，复用现有公式拓扑节点与 SVG 画布。
- 框架映射：配置页，TOD 纯内容页面；Layout.Content + 吸顶 PageHeader.PageHeaderPro。
- 主体是复杂配置表单和实时预览；实验工具按用户边调边看的要求，采用左侧 340px 参数区、右侧弹性画布。此宽度是 playground 的任务特定布局。
- 白色页面，主体左右 32px，模块间距 40px。小屏上下排列，预览保留可用高度。
- TOD 业务规则覆盖基础配置页：没有提交步骤，不设置吸底提交栏；配置自动存储。

## 模块和组件映射
- 标题：PageHeader.PageHeaderPro；标题、返回原预览入口、重置和导出操作。
- 参数：Form / Form.Item、Select、Slider、InputNumber、Input、Switch、Button。
- 颜色：组件清单无等价颜色选择能力，降级使用原生 input[type=color]，配合 Input 十六进制编辑与校验。
- 源力颜色Token：所有颜色控件增加可搜索Select，读取当前安装的 `@arco-design/theme-ve-o-design/theme.css` 中的颜色与色阶定义，显示Token名、色样、当前解析色值和类别。按Token名、类别或色值搜索；保留“自定义色值”选项与原取色器。
- Token保存：直接保存已知Token的CSS变量表达式；RGB通道Token使用 `rgb(var(--token))`，颜色Token使用 `var(--token)`。草稿、命名方案、JSON导入导出、平铺对比及CSS导出均保留Token名称；旧的HEX配置仍兼容。手动输入或取色后转换为自定义HEX。
- 分组：画布与连线、指标卡片、函数容器、括号容器、常量、运算符；原生导航按钮切换分组。
- 文字参数：指标、函数、括号和常量可调字号、字体、颜色、字重；指标细分为名称、公式、实际值、单位、目标与偏差。
- 指标状态：指标卡片分组增加“显示状态 Tag”开关，默认隐藏，使用 Tag.TagPro 展示正常、预警、异常示例，悬停显示说明；统一覆盖普通指标和两类函数内指标，不改变卡片高度与连线位置。仅 playground 注入示例状态；草稿、命名方案、导入导出与独立平铺对比保留开关值，旧配置缺少此字段时按隐藏处理，原始样式隐藏状态。
- 指标分隔线：指标卡片分组使用现有 Slider + InputNumber 增加“分隔线左右间距（px）”，范围 0–48px，左右等距缩短公式与数值之间的灰色虚线，12px 可与字段文字左边缘对齐。默认 0px 保留原始长度，旧配置缺少字段时恢复 0px；仅调整分隔线，不改变文字内边距、卡片尺寸和连线。草稿、命名方案、独立对比及 JSON/CSS 导出保留间距。
- 方案一（2026-11-23）：一次性写入用户指定的方案一并加入原始样式对比；已有同名方案在本次生成时更新，后续刷新保留用户修改、重命名与删除。指标名称/实际值 body-3 medium = 14px/500；名称 primary-6，公式 color-text-3；目标和偏差数值独立采用 body-1 medium = 12px/500、Roboto。指标内容宽276px（外宽278px），分隔线252px，两侧各12px；配置宽度可调260–360px，布局测量和连线锚点同步，原始对比仍300px。括号标题/图标 #1AC6FF、标题底色 #E6FDFF、描边 #94EFFF、底色 #F3FEFF；两类函数标题/图标 #FF8A00、标题底色 #FFF2D6、描边 #FFCE7A，公式函数底色 #FFF8EB，单指标函数底色保留白色。指标、括号及函数圆角8px，所有节点无阴影；标题图标使用原SVG的CSS mask继承文字色。数值字体与单指标函数背景色可独立调整，旧JSON按旧字段补齐新增参数。
- 方案二（2026-11-23）：复制已保存方案一后一次性初始化并加入对比；实际值18px/500 Roboto，固定22px行高，运算符圆底 `var(--color-bg-4)`。函数与括号使用Figma 5394:485720/485721的斜边Tag和单个连续SVG外框，虚线3/3、圆角8，内容框顶边y=26，内容原点(13,39)，底部9px；函数统一浅橙底#FFF8EB，括号浅青底#F3FEFF。括号图标使用用户提供的花括号与三点SVG，16px/#1AC6FF。函数/括号提供classic/folder形态切换，括号提供原始/三点图标切换，旧JSON默认classic/original。嵌套测量与节点、连线落点共享形态配置；原始及方案一继续原形态，后续刷新保留方案二修改。
- 预览：FormulaCanvas，原始 RocketMQ 模型与含全部节点类型的示例模型；缩放、平移、适配、展开收起。
- 综合样式mock：默认加载同一张图内包含普通指标、MAX函数单指标、SUM函数多指标公式、嵌套括号、常量和运算符的综合示例。单指标函数使用 `variant="metric"`，公式函数使用 `variant="formula"`；根值按mock公式计算，目标字段包含正负偏差。保留原简单示例及RocketMQ模型；方案对比共享新mock数据。
- 对比节点展开收起：综合示例的普通指标、单指标函数内指标及括号内指标补充两项可展开的mock下层数据，初始仍仅展开根节点。每张对比图使用原MetricTopologyNode展开按钮，状态与主预览、其他方案同步；节点可独立展开收起。对比选择栏复用源力Button增加“全部展开 / 收起下层”，无需返回主预览操作；未选择对比项时禁用。批量收起只保留根节点展开，批量展开包含模型全部有子节点的指标。规范映射：沿用配置页框架、对比模块、现有Button/节点组件、共享展开状态及批量操作闭环；不新增页面或弹窗。
- 对比区缩放下限为0.1，支持多分支展开后的适配画布，主预览保持0.25；共享FormulaCanvas通过可选参数配置。
- 方案二展开按钮留白：函数/括号直接包含可展开指标时，底部padding21px，确保可见圆形底部距外框描边内侧8px；无直接按钮时仍9px。递归高度及连线测量同步更新。
- 公式函数外层的底部留白为12px：最高嵌套内容底部距函数描边内侧12px，基础padding13px（含描边），展开圆形仍保留8px净空；单指标函数和括号继续原留白规则。
- 方案二指标名称到计算公式文字块的间距为8px（原10px），metric.formulaGap可编辑8–32px，默认10px兼容旧JSON。主预览及各方案递归布局高度随间距同步，已有方案二仅一次性补充8px字段。
- 画布参数：背景色，点阵/线网格/关闭，网格颜色、间距和大小；连线颜色、粗细和虚线。
- 节点参数：描边颜色、背景色、圆角、边框线型、阴影；容器额外配置标题底色。
- 函数与括号标题Tag：非原始方案的标题向上补偿1px边框偏移，底边与卡片外侧顶边对齐，避免遮住相交位置的虚线；卡片尺寸和连线锚点保持不变。
- 运算符图标：原始样式、当前调整、预设及保存方案统一使用 CalculationOperatorNode 的原始加减乘除 SVG，保留原图笔画、描边、尺寸及容器定位，不再用字体字符与伪元素替换。原SVG内联，只将圆形背景填色开放为CSS变量；运算符分组可启用自定义背景色，默认关闭，旧JSON按关闭处理。方案一启用背景 `var(--color-bg-1)`，一次性仅更新已保存方案一的该参数，后续保留用户调整；原始图标仍保留原底色 #FCFDFE。JSON/CSS导出保留Token。
- 预设：原始、蓝色、暖色、深色；原始预览开关临时对照，关闭后恢复当前配置。
- 配置闭环：实时更新、不重置画布视角；自动存储、JSON 导入导出、CSS 导出、重置当前分组与全部。
- 命名方案：新增“保存为方案”，使用 Modal（480px）+ Form + Input 输入名称；默认依次为方案一、方案二，名称去除首尾空格、不能为空、不能重名，最长40字。
- 方案切换：Select 加载方案的独立样式快照；调整已加载方案显示“有未保存修改”。提供显式更新、另存、重命名及删除。任何草稿编辑都不自动改写已保存方案。
- 方案管理和对比：在配置工作区下方提供全宽方案区，Checkbox 多选原始样式、当前调整及已保存方案；保存新方案后自动加入对比。
- 平铺对比：等宽画布沿水平方向排列，超宽时只在对比区内横向滚动。共享模型、目标字段、展开状态，以及缩放和平移视角。原始样式使用节点组件原生样式；每份方案使用独立CSS作用域和独立SVG箭头ID。
- 本地保存：方案列表和对比选择使用独立带版本的localStorage键；保留旧的草稿自动保存。刷新恢复方案与对比选择。写入失败显示错误，不提示保存成功；删除已保存方案需确认。

## 约束与状态
- 预览样式限于 playground，原产品页面不受影响。
- 字号 10–18px，不改变原布局字段行高；指标宽度开放260–360px并同步布局坐标，不开放字段内边距。
- 导入只接受已知键、有效HEX或主题目录内的Token、范围内数字、枚举选项，非法配置保持当前状态并显示错误；不接受任意CSS表达式或未知Token。
- 颜色输入允许编辑中间态，格式有效后更新预览。
- 所有颜色与数值控件有可访问名称；即时反馈使用 Message。
- 对比空态提示选择方案；没有保存方案时提示先保存当前调整；重名和空名称的错误显示在命名表单下。
- 未找到配置页专项验收文档，采用通用布局、间距、交互和键盘可访问性检查。
