# 拓扑图 Playground

## 页面整体架构
- 独立入口 `/topology-playground.html`，复用现有公式拓扑节点与 SVG 画布。
- 框架映射：配置页，TOD 纯内容页面；Layout.Content + 吸顶 PageHeader.PageHeaderPro。
- 主体是复杂配置表单和实时预览；实验工具按用户边调边看的要求，采用左侧 340px 参数区、右侧弹性画布。此宽度是 playground 的任务特定布局。
- 白色页面，主体左右 32px，模块间距 40px。小屏上下排列，预览保留可用高度。
- TOD 业务规则覆盖基础配置页：没有提交步骤，不设置吸底提交栏；配置自动存储。

## 模块和组件映射
- 标题：PageHeader.PageHeaderPro；标题、返回原预览入口、重置和导出操作。
- 参数：Form / Form.Item、Select、Slider、InputNumber、Input、Switch、Button。
- 颜色：组件清单无等价颜色选择能力，降级使用原生 input[type=color]，配合 Input 十六进制编辑与校验。
- 分组：画布与连线、指标卡片、函数容器、括号容器、常量、运算符；原生导航按钮切换分组。
- 文字参数：每类可调字号、字体、颜色、字重；指标细分为名称、公式、实际值、单位、目标与偏差。
- 预览：FormulaCanvas，原始 RocketMQ 模型与含全部节点类型的示例模型；缩放、平移、适配、展开收起。
- 画布参数：背景色，点阵/线网格/关闭，网格颜色、间距和大小；连线颜色、粗细和虚线。
- 节点参数：描边颜色、背景色、圆角、边框线型、阴影；容器额外配置标题底色。
- 预设：原始、蓝色、暖色、深色；原始预览开关临时对照，关闭后恢复当前配置。
- 配置闭环：实时更新、不重置画布视角；自动存储、JSON 导入导出、CSS 导出、重置当前分组与全部。

## 约束与状态
- 预览样式限于 playground，原产品页面不受影响。
- 字号 10–18px，不改变原布局字段行高；不开放影响布局坐标的节点宽度和内边距。
- 导入只接受已知键、有效颜色、范围内数字、枚举选项，非法配置保持当前状态并显示错误。
- 颜色输入允许编辑中间态，格式有效后更新预览。
- 所有颜色与数值控件有可访问名称；即时反馈使用 Message。
- 未找到配置页专项验收文档，采用通用布局、间距、交互和键盘可访问性检查。
