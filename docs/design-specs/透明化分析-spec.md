# 透明化分析：计费项收支表格调整

## 页面整体架构

复用现有 Dashboard 页面框架、导航、全局筛选和收支分析 Tab。本次范围为计费项收支的各资源类别收支明细表。

## 规范映射清单

- 页面框架：Dashboard_页面框架.md，使用现有页面布局。
- 模块：详情页_表格模块.md，复用计费项收支内嵌表格。
- 组件：复用业务封装 SourceTable、SourceTableSummary，保持现有分组表头、固定维度列、横向滚动和分页。
- 核心功能：成本利润率年度列依次为「年度目标」「1月至今累计值」「年度目标累计偏差」。
- 交互闭环：随全局年度目标筛选显示，随日期、商品、计费单元、区域筛选重新计算；支持升降序排序。

## 模块及字段定义

- 累计值字段为 accumulatedRate：选定月份所在年度 1 月至选定月的累计利润 ÷ 累计成本 × 100%，复用 financialMetricValue 的计算口径。
- 总计使用全体选中数据累计利润 ÷ 累计成本，不对各行利润率做算术平均。
- 使用 tablePercent 展示累计值，保留两位小数，右对齐；无可比成本或成本为零时沿用缺失值展示。
- 累计值列宽 182px；年度偏差列保持 174px，标题改为「年度目标累计偏差」。
- 偏差使用已有 metricDeviation，累计成本利润率与年度目标比较，沿用趋势颜色和箭头。
- 同步 columns 与 flatFields，保证表头、明细、总计和横向滚动宽度一致。

执行生产构建，并验证年度列显示、累计值及总计、排序、年度目标筛选开关。保持现有表格组件默认交互与样式。
