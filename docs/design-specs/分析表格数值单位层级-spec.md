# 分析表格数值单位层级

## 规范映射与自检
- 页面框架：沿用商品经营归因分析 Dashboard 及现有三个 Tab。
- 模块：经营现状、收支分析明细、成本分析明细、计费项收入价格、公式指标趋势明细及各表总计行。
- 组件：沿用 SourceTable / DataTable、SourceTableSummary；共享 TableNumberValue 负责表格数值结构。
- 核心功能：数值与缩写使用主文本色，实际单位使用三级文本色；不改变原始数值及排序字段。
- 交互闭环：筛选、排序、分页、总计、下钻和目标列显隐保持原行为。

## 数值显示契约
- 所有表格内嵌单位使用 `var(--color-text-3)`。
- 数值主体使用 `var(--color-text-1)`；已有亏损状态色继续沿用。
- 百分比拆分为数值与 `%`，其中 `%` 为单位。
- 金额数值与单位之间为 0 间距，不插入空格。
- 金额达到万元或亿元时，`万`、`亿`属于数值缩写，跟随数值主体使用主文本色；只有末尾 `元` 使用三级文本色。
- 数量达到万或亿时，`万`、`亿`作为数值缩写使用主文本色。
- 单独的单位列属于纯文本字段，Header 统一为“单位”，内容使用普通 Text 单元格样式；只有数值单元格内嵌的实际单位使用三级文本色。
- 缺失值继续展示 `—`，使用三级文本色。

## 覆盖范围
- 总览：收入、成本、利润、成本利润率、售卖率及涨跌数值。
- 收支分析：实际值、各周期目标、累计实际值、累计占比、偏差及总计行。
- 成本分析：物理容量、成本合计、成本商品金额、构成金额及总计行。
- 成本定价：测算单价、目标单价、公式指标实际值/目标值、比率、数量及偏差。
- Header 不做任何调整。

## 验收约束
- `715.47万元` 中 `715.47万` 为主文本色，`元` 为三级文本色，字符间无空格。
- `5.02亿元` 中 `5.02亿` 为主文本色，`元` 为三级文本色，字符间无空格。
- 普通金额如 `128.00元` 无空格，只有 `元` 使用三级文本色。
- 百分号和独立单位列使用三级文本色。
- 明细与总计的格式规则一致，排序仍按原始数值执行。
