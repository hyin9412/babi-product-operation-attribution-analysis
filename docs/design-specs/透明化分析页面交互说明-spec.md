# 透明化分析页面交互说明

## 页面架构与标注
- 现有交互说明详情页：顶部标题与说明，左侧纵向 Tabs，右侧对应章节。
- 标题：“透明化分析页面交互说明”。
- 说明：“用于给产研团队枚举不同的交互细节，前端实现的一些规则”。
- 用户截图明确指定纵向 Tabs，采用该布局分支，保留原有章节内容。
- 整个交互说明页面上下各留20px间距，统一由主页面容器的上下padding提供。
- 所有白框Section的主标题统一采用表格说明章节的标题样式：18px、字重600、行高26px、无蓝色竖线及左内边距，距下方内容12px；标题同行的链接与状态Tag继续保留。用户指定此样式覆盖源力标题规范。

## 组件和交互契约
- 使用 `@tod-m/materials/ve-o` 的真实 Tabs：`tabPosition="left"`、`type="line"`、`activeTab`、`onChange` 与 `Tabs.TabPane`。
- 保留五个章节名称及顺序；仅替换左侧导航。取消原导航卡片背景、边框和圆角，沿用源力默认纵向标签与指示线。
- 第一个 Tab 名称为“商品经营结论卡片”。纵向标签头部撑满导航宽度，蓝色选中竖杠与灰色分隔线共用右侧边界。
- Tab 文字取消左内边距，与页面标题左侧对齐；Tab 栏宽度由240px缩小为160px，内容区随之拓宽。
- Tab 切换显示对应章节，保留 URL hash 与初始定位；窄屏延续现有上下布局。
- HTML 文档通过独立 React 入口挂载 Tabs；预览构建处理模块与样式，发布目录同步编译后的文档。
- 表格说明分为三个独立Section：表格优先级列、偏差/环比数值样式、数据明细表趋势图icon位置。各章节标题、正文、表格与右侧内容区共用左边界；章节无额外左右内边距，间距40px，首章顶部无额外间距。保留数值示例的右对齐规则。
- 本次规范映射：沿用详情页及纵向Tabs；将现有表格说明按章节组织；复用现有表格、图标与示例组件；核心验收为标题/正文/表格左边界一致，宽窄屏可读且数值样式不变。
