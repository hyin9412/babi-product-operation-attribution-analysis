# 交互说明表格偏差与环比

## 页面与规范映射
- 源文件：`public/docs/operation-conclusion-card-guide-topology.html`；构建后发布为 `docs/docs/operation-conclusion-card-guide-topology.html`，修改源文件避免发布同步覆盖。
- 框架：详情页；沿用现有文档标题、导航、内容布局。
- 模块：既有优先级列示例、新增偏差与环比示例、趋势图入口位置说明。
- 组件：只读数值直接显示文本，使用现有文档表格；原生 SVG 原样复用业务图标。
- 核心功能：展示上涨、下跌、持平、不可比状态，以及 `%` / `pp` 单位。
- 交互闭环：点击表格导航显示新增内容；支持表格横向滚动。

## 原样复制契约
- 来源：`src/pages/analysisUI.tsx` 的 `TrendValue`、`src/pages/analysis.css` 的 `.table-trend-*`，以及 `src/app/static/icon/环比icon正.svg`、`环比icon负.svg`、`环比icon无变化.svg`。
- 数值 13px、字重 400、行高 22px，整体右对齐；图标 12×12px，图标与文本间距 4px，数值和单位之间无额外间距。
- 上涨使用原红色渐变箭头，下跌使用原绿色渐变箭头；数字保持正文色，单位使用次级灰色。
- 正值有 `+`，负值有 `-`，保留两位小数；零显示灰色持平图标与 `0.00`；不可比显示 `—`、不显示方向图标。
- 年度目标累计占比属于普通比例，不套用涨跌样式。
- 示例覆盖月度偏差、季度偏差、收入环比、成本环比、成本利润率年度目标累计偏差。

## 趋势图入口规则
- 支持售卖区域：趋势图 icon 位于售卖区域列。
- 有的商品不支持售卖区域，数据明细表里的趋势图 icon 位于大区列。

## 验收
- 比较文档与实际透明化分析表格中相同数值的字体、间距、颜色和 SVG 路径。
- 确认表格页签新增示例、单位和规则说明可见。
- 文档为 Vercel 直接发布的静态文件，资源必须在发布目录内自包含。
- 已验证：表格页签、五类状态、售卖区域规则可见；与实际表格的数值、图标、正文和单位计算样式一致，SVG 路径与渐变一致，无运行错误。
