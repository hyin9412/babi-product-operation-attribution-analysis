# 商品经营结论模块

## 规范映射

- 页面框架：Dashboard 页面框架。
- 模块位置：商品概览 Tab 首屏，位于「经营现状」之前。
- 组件：复用 Section、源力 Tag 和 SemanticMetricCard。
- 核心功能：展示经营状态、主要风险、目标差距趋势和动作边界。
- 交互闭环：随全局商品、账期、计费单元、大区、售卖区域及目标筛选同步刷新；结论卡片不单独持有筛选状态。

## 展示规则

- 标题为「商品经营结论」，状态 Tag 紧跟标题。
- 四张语义卡片保持一行 4 列，并沿用现有 2 列、1 列响应式断点。
- 经营状态根据可比成本及利润正负切换中性、绿色或红色。
- 主要风险展示亏损大区数量及最多三个大区名称。
- 目标差距趋势使用最近两期利润月度偏差判断收窄、扩大或持平。
- 动作边界固定展示「暂不直接调价」及评审条件。
