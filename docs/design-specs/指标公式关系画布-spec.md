# 指标公式关系画布设计契约

## 1. 页面与模块映射

- 页面框架：沿用 Dashboard 页面框架，不调整现有顶部导航、侧导航、全局筛选和成本定价页签。
- 改造范围：仅替换“指标公式”模块的递归卡片排布。
- 模块类型：数据关系画布，用于展示指标公式的父子拆解关系。
- 组件选型：使用项目内 `TopologyCanvasShell` 承载节点、边、缩放、平移和视图适配；指标节点使用独立 `MetricTopologyNode`，运算节点使用独立 `CalculationOperatorNode`，常量节点使用独立 `ConstantTopologyNode`；悬浮详情使用现有 Popover，趋势图标使用 VE-O 图标库，展开/收起和运算符使用 `src/app/static/icon` 中的设计稿 SVG。

## 2. 画布结构

- 选择器行底部到指标公式模块顶部的间距为 16px，由公式容器的上外边距统一控制，不叠加选择器下外边距或容器顶部内边距。
- “指标公式”标题不显示蓝色装饰竖条，不保留竖条占用的左侧间距。
- 标题下方为单一全宽画布，不在画布外重复渲染各层卡片。
- 画布高度为 `calc(100vh - 300px)`，宽度撑满内容区；节点较多时通过平移和缩放查看，不挤压页面布局。
- 根指标位于第一层水平居中；展开后，其下一层按计算公式原始顺序生成单行表达式。
- 表达式行可混排指标节点、括号表达式、函数、计算式子和常量节点；所有直接子项横向展示，以当前行最高节点的垂直中心线（centerY）居中对齐。括号与函数内容区递归遵循相同规则。
- 公式中的括号必须聚合为 `BracketExpressionNode`，函数必须聚合为 `FunctionTopologyNode`，不得降级为普通文本 token。
- 每个表达式项保留独立布局单元；可展开指标的后续表达式宽度计入该单元，避免相邻分支互相覆盖。
- 节点宽度固定为 300px；高度按当前展示的目标行数量和下级节点控制器自适应，同层节点位置按该层最大高度计算。
- 计算式子按公式出现位置直接排列在相邻操作数之间，不再作为层间统一节点。
- 先计算所有操作数的最终 X 坐标，再设置运算符 `x = (左节点 x + 左节点宽度 + 右节点 x) / 2 - 运算符宽度 / 2`；子级展开后同样按可见边缘间隙居中。

## 3. 节点内容

- 标题：指标名称必填，单行省略；与右侧月趋势图标至少间隔 6px，仅在文字溢出时悬浮展示完整名称。
- 操作区：
  - 有子指标时显示展开/收起图标按钮。
  - 支持趋势的指标在标题右侧显示月趋势图标按钮。
- 公式：计算公式必填，最多两行并始终保留 40px 文本高度；溢出时悬浮展示完整公式，没有公式内容时显示 `-`。
- 实际值与单位：同行展示并沿用当前格式与精度；实际值为百分比时不渲染单位，不追加 `-`、`%` 或“指标”；其他实际值或单位缺失时显示 `-`。
- 目标区：月度、季度、年度目标为可选行，仅在全局筛选选中对应目标时展示，同时展示目标值与偏差。
- 多行数据状态：当指标计算结果返回多行时，公式下方不展示聚合后的实际值、目标值或偏差，改为文本按钮“请点击查看详细数据”。按 Figma `5364:326040`，整段使用 12px/20px 常规字重和 `#737A87`，仅“点击”二字使用 `#1664FF`。
- 多行数据区水平、垂直居中；高度与普通指标节点一致，使用 `46px + 当前全局筛选已选目标类型数 × 24px`。未选择目标时为 46px，同时选择月度、季度、年度目标时为 118px。
- 卡片使用白底、`#DDE2E9` 描边、12px 圆角和基础卡片阴影；叶子节点不显示展开按钮。
- 常量节点：按 Figma `5362:325775` 还原，固定高度 32px，最小宽度 32px，宽度随数值内容自适应；数值不换行，文字距节点左右边缘 12px，使用白底、`#DDE2E9` 描边、8px 圆角和基础卡片阴影。
- 运算节点：
  - 支持加、减、乘、除四种类型，分别使用 `计算式子_加.svg`、`计算式子_减.svg`、`计算式子_乘.svg`、`计算式子_除.svg`。
  - 固定为 46px 见方的纯展示节点，不可点击，不显示 Tooltip。
  - hover、active 均不改变颜色、阴影、尺寸或位置。

## 4. 连线

- 每个展开指标与其直接表达式行绘制自上而下的圆角正交折线，连线类型统一为 `smoothstep`。
- 路径统一使用 React Flow `getSmoothStepPath`，源端方向为 `Position.Bottom`，目标端方向为 `Position.Top`。
- 同一父节点的分支共用 `centerY = 表达式行顶部 - 层间距 / 2`，形成整齐的水平横梁；各目标节点高度差只影响末端竖线长度。
- 连线宽度统一为 1.5px，从父指标底部中心分叉连接到表达式行各直接子项顶部中心；计算式子不生成纵向连线。
- 各节点的纵向偏移为 `(行最大高度 - 节点高度) / 2`；连线落点及嵌套指标的下级布局必须计入此偏移。
- 分组节点的主体为虚线框，Tag 绝对定位在框外，不参与主体高度或中心计算；父连线 target 对应分组节点 ID，落于虚线框顶部正中。
- 终点 Connector 按 Figma `8032:13114`：13×12px 向下 V 形端点，填充和描边均为 `#D0D9E5`，描边按本次要求为 1.5px，圆角线帽与圆角连接；不使用原蓝色三角箭头。
- 展开节点时生成其直接子节点与连线；收起节点时隐藏全部后代节点和相关连线。
- 同一父节点的多条连线应清晰分叉，不穿过节点正文。
- 指标、分组和运算符在左右边缘 centerY 提供隐藏 Handle：`right / Position.Right / source`、`left / Position.Left / target`。
- 同一表达式行按相邻元素生成 `straight` 灰色虚线横向边，无箭头；单侧可见边缘间隙大于 30px 时显示，否则隐藏。横向边与纵向 smoothstep 分支独立计算。

## 5. 交互闭环

- 初始状态：根节点默认展开，展示根节点及其直接下一层；更深层级保持收起。
- 展开/收起：操作后重新计算树布局，并自动适配当前可见节点范围。
- 公式匹配：依次解析指标引用、四则运算、数字常量、括号与函数；优先匹配当前指标全部后代中的完整指标名称，再匹配省略业务前缀的简称。
- 兼容旧数据：公式无法解析出依赖指标时，按 `children` 顺序和节点默认 `operator` 生成表达式，禁止展示空白下层。
- 月趋势：保持现有行为，选择对应指标并滚动到“指标趋势”模块。
- 画布交互：支持滚轮缩放、拖拽平移、控制器缩放和一键适配；节点不可任意拖动，确保公式层级稳定。
- 画布背景保持白色，可使用克制的点阵辅助定位。
- 键盘可聚焦节点操作按钮，按钮保留明确的 aria-label。
- 多行详情：点击“请点击查看详细数据”后，从右侧打开 960px Drawer；标题为“查看指标详细数据”，右侧以 8px 间距展示源力 Label Tag，左段固定为“指标”，右段展示当前指标名称，整体高度为 20px；正文去掉重复的指标小标题，直接展示基础 Table。表格内数字保持主文本色，金额、数量、单价及百分比的单位统一使用 `--color-text-3`。
- 详情表固定展示指标维度打标列、单位、实际值；本页面指标维度打标列映射为“计费单元”“大区”“收入售卖区域”。月度、季度、年度目标及其偏差列分别跟随全局目标筛选显隐。
- 详情表数值右对齐，空值展示 `-`，内容超宽时横向滚动；小数据集不显示筛选区，单页时隐藏分页器。

## 6. 响应式与状态

- 桌面端显示完整树；窄屏保持节点固定宽度，通过画布平移查看，不压缩节点文本。
- 空数据时沿用现有 EmptyState。
- 切换计费单元、大区或收入售卖区域后，重置为全部收起并重新适配视图。
- 切换目标值筛选只更新节点内容，不改变树层级。

## 7. 验收清单

- 根节点、一级、二级和三级节点均能按数据关系展开。
- 每个可见的非计算式子子节点都只有一条来自直接父节点的连线；计算式子无纵向连线。
- 收起节点后，其全部后代和连线消失。
- 展开后节点不重叠，连线不穿过节点内容。
- 月趋势操作与改造前一致。
- 画布在桌面和窄屏下无页面级横向溢出。
- 浏览器控制台无画布、尺寸或重复节点 ID 错误。
