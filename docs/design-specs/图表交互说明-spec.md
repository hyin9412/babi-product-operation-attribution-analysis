## Top N 排名与输入规则

- 沿用详情页、图表信息模块及 `TrendRangeControl` / `InputNumber`，编号 2 继续指向输入器。
- label 为「排名指标 Top N」，按对应图表的需求提供实际值或成本合计，必须与真实排序字段一致。
- 默认 N 由业务需求配置，本需求为 5；清空并失焦或按 Enter 后展示全部，输入器保持空白，placeholder 为「全部」。
- 按当前筛选条件和图表规定的统计口径，对计费项的排名指标降序取前 N 项；同值顺序稳定，缺失值排末尾。N 控制计费项数量，不控制系列数量。
- N 大于可用计费项数时展示全部可用项，但保留输入值；正整数范围 1–2147483647，数值输入沿用组件精度与边界约束。
- 结构示例使用六个计费项，初始展示前五个；提供实际值及成本合计两种 label 示例。
- 验收默认 5、清空 Enter／失焦展示全部、重新输入 N、成本 label、全屏及外部 range 更新同步。

- 规范映射：沿用详情页图表信息模块及现有说明表格，尺寸和断点以本项目 `AnalysisChart`、`analysis.css`、`overview.css`、`PricingTab` 的实际配置为准。
