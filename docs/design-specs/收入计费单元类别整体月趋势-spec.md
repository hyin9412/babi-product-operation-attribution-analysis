# 收入计费单元类别整体月趋势

## 规范映射清单
- 页面框架：Dashboard；沿用收支分析现有卡片布局，同一行图表等高。
- 模块：计费项收支下整体月趋势，包含成本利润率、收入、成本、利润四图。
- 组件：复用 AnalysisChart、Fold、MultiFilter；图表模块无独立规范，沿用项目图表封装的真实 API。
- 核心功能：filters.targets 控制月度、季度、年度目标的数据、曲线和图例。
- 交互闭环：目标筛选和类别筛选更新四图；图例排除、隔离沿用现有行为。

## 数据及样式契约
- 实际值为所选类别按月汇总值；峰值提示仅统计实际值。
- 月度目标复用 financialTargetValue；季度目标沿用已有月趋势口径，金额除以当季度已覆盖月份数，比率直接展示。
- 年度目标复用 annualTargetValue 与页面年度目标相同的全年数据范围；金额展示全年目标，比率直接展示。
- 未勾选的目标不生成系列；全部取消时只展示实际值。
- 单类别按实际值及已选目标的展示顺序使用色板中的不同颜色。
- 多类别按类别分配颜色，同类别实际值和各目标同色。
- 目标系列均使用 dashedSeries，实际值保持实线；图例、浮层和曲线颜色同步。
- 缺失成本、利润及利润率数据保持 null；无类别时沿用空态。

## 验收约束
- 核对全部目标组合及单类别、多类别的系列数、颜色映射、虚线配置。
- 复用既有色板、图例和图表布局，保持四图一致。
