# 分析表格排序提示

## 规范映射与自检
- 页面框架：沿用商品经营归因分析 Dashboard 及现有 Tab。
- 模块：所有使用 SourceTable / DataTable 的分析表格。
- 组件：沿用 Table 原生排序能力；关闭内置 Tooltip，通过共享 SourceTable 使用源力 AnalysisPopover 展示排序提示。
- 核心功能：Hover 排序图标时展示白底 Popover 视觉提示。
- 交互闭环：升序、降序、取消排序、受控排序状态、分页及表格滚动行为均保持不变。

## 浮层契约
- 排序提示根据下一排序状态沿用原文案：“点击升序”“点击降序”“取消排序”。
- 浮层使用白色弹层背景、深色正文、浅色边框、4px 圆角与轻阴影，并保留指向排序触发区域的白色箭头。
- 通过共享 SourceTable 为可排序列统一注入源力 AnalysisPopover，不逐列重复配置。
- 浮层关闭后销毁 DOM，避免多个表格的排序提示残留。

## 边界
- 不修改 Header 文案、排序图标、排序方向或点击热区。
- 无排序能力的列不出现提示。
- 表格外其他 Tooltip / Popover 不受影响。

## 验收
- 商品概览、收支分析、成本分析与成本定价中的所有可排序列均使用白底浮层。
- 当前未排序、升序、降序状态下提示内容与改动前一致。
- Hover 离开后浮层正常关闭，排序点击、分页与横向滚动保持可用。
