# 归因分析图表 Tooltip 金额缩写设计契约

## 页面架构结论

- 页面类型：经营分析 Dashboard。
- 影响模块：归因分析页共享图表 Tooltip 与图表样式 Playground。
- 页面框架、路由、图表类型和现有 Tooltip 外观保持不变。

## 规范映射清单

- 页面框架命中：`Dashboard_页面框架.md`。
- 模块命中：Dashboard 内容区中的共享图表模块。
- 组件命中：复用现有 VChart Tooltip，不新增替代组件。
- 核心功能命中：金额按万、亿自动缩写并保留 2 位小数。
- 交互闭环命中：Playground 统一开关同时影响单点与同维度 Tooltip；业务图表按金额单位自动应用。

## 数据与状态规则

- 金额绝对值达到 100,000,000 时除以 100,000,000，追加“亿”，保留 2 位小数。
- 金额绝对值达到 10,000 时除以 10,000，追加“万”，保留 2 位小数。
- 金额绝对值不足 10,000 时保持原有本地化数值格式。
- 负数保留负号，并按绝对值判断缩写档位。
- 人民币、CNY 或独立“元”单位识别为金额；百分比和数量单位不缩写。
- Playground 的金额自动缩写开关默认开启，关闭后恢复原有完整数值。
