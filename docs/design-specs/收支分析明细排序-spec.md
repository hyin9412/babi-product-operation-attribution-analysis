# 收支分析明细排序

## 规范映射
- 框架：既有商品经营归因分析 Dashboard。
- 模块：收支分析 Tab 内收支明细、计费项成本表格。
- 组件：沿用 SourceTable / TableBlock.Table 的 sorter、sortOrder、sortDirections、onChange。
- 核心功能：指标按原始数值排序，升降序独立切换。
- 交互闭环：每张表独立排序，取消排序恢复默认，总计行固定且不参与排序。

## 排序规则
- 收支明细默认按成本利润率的实际值降序。
- 成本利润率、收入、总资源成本、毛利的全部子列可排序，包括实际、目标、偏差、累计实际值和年度目标占比。
- 计费项成本默认按成本合计降序；全部商品成本列可排序，包括 Abase、其他商品、强一致的键值数据库、ByteStore池化存储及 TOS 的商品成本列。
- 点击未排序列先降序，再升序；缺失值置后；排序发生在分页之前。
- 延续既有标准表格、数值右对齐和双层表头分割线。
- 共享封装保留显式列 key；可排序列无显式 key 时使用 dataIndex，避免回调返回位置编号而无法取到业务数值。
