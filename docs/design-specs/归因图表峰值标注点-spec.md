# 归因图表峰值标注点设计契约

## 页面架构结论

- 页面类型：经营分析 Dashboard。
- 影响模块：归因页中已开启“更多信息”Tag 的折线图。
- 页面框架、图表标题、更多信息 Tag、图例和 Tooltip 保持不变。

## 规范映射清单

- 页面框架命中：`Dashboard_页面框架.md`。
- 模块命中：归因趋势图与峰值信息模块。
- 组件命中：复用现有 `AnalysisChart` 和 VChart 折线数据点。
- 核心功能命中：按“峰值”信息在对应数据点显示标注。
- 交互闭环命中：峰值有效且更多信息开启时显示；峰值系列被图例排除时同步隐藏。

## 标注点规则

- 参考 Figma 节点：`5341:151116` 中的“1.标注点”。
- 标注对象：图表范围内数值最大的有效数据点，与“峰值”Tag 使用同一份结构化数据。
- 形状：实心圆点。
- 尺寸：`8px × 8px`。
- 颜色：`#E8002A`。
- 描边：无。
- 标签：不额外显示文字或浮层。
- Tooltip 悬停到峰值月份时，在峰值所属系列的 Label 右侧显示“峰值”Tag。
- Tooltip 的“峰值”Tag 使用浅红背景 `#FFECEC`、红色文字 `#D7312A`，高度 `18px`，与 Label 间距 `4px`。
- 非峰值月份及同月份的其他系列不显示“峰值”Tag。
- 无有效峰值、未开启更多信息或非折线图时不显示标注点。
- 标注点不改变折线颜色、图例、Tooltip 或坐标轴范围。
