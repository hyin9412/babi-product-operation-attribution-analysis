# 图表图例尺寸

- 页面框架及组件：沿用现有 Dashboard、AnalysisChart、ChartLegend 和 VChart tooltip。
- 所有页面图表及 tooltip 的方块标记为 10×10px，保留 1.54px 圆角。
- 页面图例及 tooltip 的虚线标记宽度均为 10px。
- Playground 字段初始值及保存默认值同步采用方块 10px、虚线 10px。
- 保留配色、虚线指标映射、图例分页、tooltip 最大 400×500px、Label 折行及与数值至少 28px 间距。
- 验证实际 DOM 方块宽高、虚线 SVG 宽度及 playground 默认值。
