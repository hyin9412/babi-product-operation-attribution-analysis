# 函数节点设计契约

## 1. 页面与模块映射

- 页面框架：沿用现有指标公式关系画布，不调整页面导航、筛选或画布交互。
- 改造范围：新增画布复合节点 `FunctionTopologyNode`。
- 模块类型：函数节点，分为函数单指标和函数内为公式两种结构。
- 组件选型：类型 Tag 使用函数图标资源；内容复用项目内 `MetricTopologyNode`、`BracketExpressionNode`、`CalculationOperatorNode`。

## 2. 函数单指标

- 使用 `variant="metric"`，指标节点置于函数虚线外壳内，函数类型 Tag 绝对定位于外壳左上角外侧。
- 指标内容通过 `metric` Props 调用 `MetricTopologyNode`，不复制或改写指标节点内部结构。
- 指标节点保持 300px，外壳增加左右 16px 内边距与边框；Tag 不参与主体高度计算。

## 3. 函数内为公式

- 使用 `variant="formula"`，最外层节点直接作为虚线内容区，设置 `position: relative`；公式内容通过内部 flex 行排列。
- 两种函数结构的内容区均为白底、浅色 1px 虚线描边、四角均为 12px 圆角、基础卡片阴影和 16px 内边距。仅通过伪元素在左上圆角外侧缺口补上 Tag 紫色 `#F2EAFB`，不覆盖圆角虚线描边。
- 内容区根据 `items` 顺序横向展示，以当前行最高节点的垂直中心线（centerY）居中对齐，相邻内容间距固定为 16px；嵌套函数递归遵循同样规则。
- 内容区存在直接子括号表达式或函数节点时，顶部内边距额外增加 24px，即从 16px 增至 40px，为子节点类型 Tag 留白；其他方向保持 16px。画布同步增加主体高度并修正内部指标锚点，逐层独立判断，不按子节点数量累加。
- `expression` 调用 `BracketExpressionNode`，`metric` 调用 `MetricTopologyNode`，`operator` 调用 `CalculationOperatorNode`，`constant` 调用 `ConstantTopologyNode`，`function` 递归调用 `FunctionTopologyNode`。
- 设计稿中的节点数量和顺序仅作示意；实现不写死内容，空数组保留空内容区。

## 4. 类型 Tag

- 背景色 `#F2EAFB`，文字与图标颜色 `#6E4C9F`。
- 图标 16px，图标与文字间距 6px；通过 `align-items: center` 垂直居中，不给图标添加顶部偏移。
- 函数文字统一为 `XX 函数`，函数名与“函数”之间保留一个空格，已有“函数”后缀不重复添加。
- 文字 12px / 20px，中字重；内边距 `2px 16px`。
- 上侧圆角 12px，下侧圆角 0；Tag 绝对定位于 `top: -24px; left: 0`，通过 `margin-left: -1px` 补偿主体边框，使左侧与内容框外边缘对齐，底部紧贴上边框，不撑高虚线主体。
- target 锚点位于虚线框顶部正中（`Position.Top`、`type="target"`、`left: 50%`、`top: 0`）；父连线通过分组节点 ID 定位。在 React Flow 中使用原生 Handle，在 SVG 画布中使用等价坐标锚点。

## 5. 规范映射清单

- 页面框架命中：指标公式关系画布。
- 模块命中：函数复合节点。
- 组件命中：函数类型 Tag、指标节点、括号表达式节点、计算式子节点。
- 核心功能命中：单指标函数、数据驱动公式函数、有序混排。
- 交互闭环命中：子节点交互原样保留，函数容器不新增操作。

## 6. 验收清单

- 单指标分支复用原指标内容与交互，外层虚线分组与公式分支采用相同锚点和 Tag 定位规则。
- 公式分支所有直接内容项水平排列且间距均为 16px。
- 括号表达式、指标和四类计算式子均调用已有组件。
- 内容数量、类型和顺序完全由 `items` 决定。
- 浏览器控制台无重复 key、资源加载或无效嵌套错误。
