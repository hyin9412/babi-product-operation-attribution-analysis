# 交互说明入口

## 规范映射清单

- 页面框架命中：沿用透明化分析的 Dashboard 框架，本次仅替换标题右侧入口。
- 模块命中：页面标题区域的帮助文档入口。
- 组件命中：使用原生 a 链接访问独立 HTML 文档；不使用应用内 HashRouter 路由。
- 核心功能命中：文案为“交互说明”，链接到包含拓扑图可操作预览的现有说明文档。
- 交互闭环命中：新标签页打开说明，原分析页保留当前 Tab 和筛选状态。

## 页面架构与模块契约

- 沿用现有页头、Tab 与右侧入口的布局及样式，入口文案不带清单数量。
- 目标地址：`docs/operation-conclusion-card-guide-topology.html`，相对应用部署基址访问。
- 设置 `target="_blank"` 和 `rel="noopener noreferrer"`，支持鼠标及键盘打开。
- 本次为已有页面局部入口替换，不调整页面框架或引入额外模块。

## 验收

- 三个分析 Tab 共用“交互说明”入口。
- 目标文档和文档内 iframe 的本地 HTML、JS、CSS 资源可访问。
- 原页筛选和 Tab 状态不因打开说明而变化。
