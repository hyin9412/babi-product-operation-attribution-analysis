# 商品收支图表目标线设计契约

## 页面架构结论

- 页面类型：经营分析 Dashboard。
- 影响模块：收支分析 Tab 的商品收支四张趋势图。
- 页面框架、筛选区、指标卡、图表尺寸和 Tooltip 保持不变。

## 规范映射清单

- 页面框架命中：`Dashboard_页面框架.md`。
- 模块命中：商品收支趋势图模块。
- 组件命中：复用现有 `AnalysisChart` 与共享图例。
- 核心功能命中：月度目标、季度目标按全局筛选动态增删。
- 交互闭环命中：取消目标选项时仅移除对应目标线和图例，实际值线持续展示。

## 图表规则

- 实际值使用色板第 1 个颜色和实线。
- 月度目标使用与实际值相同的颜色和虚线。
- 季度目标使用色板第 2 个颜色和虚线。
- 月度目标、季度目标在图例和 Tooltip 中均使用 10px 宽的对应颜色虚线标记；实际值继续使用方块标记。
- 月度目标选中时增加“月度目标”线及图例，取消时同步移除。
- 季度目标选中时增加“季度目标”线及图例，取消时同步移除。
- 年度目标选中或取消均不生成年度目标线及图例。
- 金额类季度目标按季度截至对应月份的累计目标折算为月均基准；利润率保持季度目标率。
