# 成本定价双 Y 轴趋势契约

## 页面整体架构

沿用 Dashboard 页面框架及现有成本定价 Tab，仅调整“单价目标差距 > 月趋势”的三张图表。图表按当前目标数量均分一行，保留现有间距、高度与全局筛选联动。

## 规范映射清单

- 页面框架命中：Dashboard，复用现有 AnalysisPage。
- 模块命中：月趋势折叠区，复用 Fold 与 analysis-chart-grid。
- 组件命中：AnalysisChart、VChart 与 ChartLegend，沿用既定配色、字体、网格、线宽与图例分页样式。
- 核心功能命中：月度、季度、年度累计三张图，左轴为金额单价，右轴为偏差百分比。
- 交互闭环命中：筛选刷新、图例显隐及仅展示、tooltip 悬浮与点击固定、内容滚动及空白处取消固定。

## 数据与模块定义

- 三个目标选中时一行三张图，两个目标选中时一行两张图，一个目标选中时单张图撑满；每张图等分所属内容区域宽度，保留 16px 图间距。
- 计费项按计费单元、大区、售卖区域完整组合区分，以 `|` 连接。
- 每个组合依次展示测算单价、目标单价、偏差幅度，再展示下一组合。
- 图例及 tooltip 名称格式：`bytegraph.cpu|cn|cn-east-1, 测算单价`。
- 年度累计单价与偏差趋势中，两个指标分别命名为“累计测算单价”和“累计偏差幅度”，目标指标仍为“目标单价”；图例及 tooltip 同步使用这些名称。
- 同组合三个指标使用同一颜色。测算单价为实线，目标单价和偏差幅度为虚线。
- 从数据明细表格钻取单个计费项时例外：偏差幅度和累计偏差幅度使用色板第二色，测算单价及目标单价仍用第一色；多个计费项趋势沿用各计费项的同色规则。
- 月度及季度使用月度测算单价，年度使用年度累计测算单价；目标和偏差计算沿用价格表口径与 TOS 单位换算。
- 两个单价指标绑定左轴，偏差幅度绑定右轴。偏差值显示 `%`，允许负值。
- 两个单位在标题下方同行展示：左侧按用户指定文字“单位：人名币”，右侧“单位：%”。右侧单位位于右 Y 轴上方，右边缘与该轴数值右对齐；轴数值采用右对齐容器。

## 实现与验收约束

复用 VChart 的 common 图、line 系列与 seriesIndex 坐标轴绑定能力。通过 AnalysisChart 可选 percentSeries 参数启用双轴，保留单轴调用行为。隐藏指标后不改配色；仅剩单价或偏差时仍保留双轴。空数据沿用 EmptyState。验证三图轴绑定、图例顺序与同色线型、tooltip 百分比及点击固定交互。
