# 交互说明全局筛选

## 规范映射与自检
- 页面框架：详情说明页，沿用现有静态文档标题、纵向 Tab 与内容布局；源文件为 public/docs/operation-conclusion-card-guide-topology.html，构建同步至 docs/docs 同名文件。
- 模块：独立「全局筛选」Tab、可操作筛选示例、查询状态说明、必填校验与联动规则。
- 组件：说明页复用现有导航和说明表格；预览复用 AnalysisSelect、MultiFilter、Field、FilterSummary、Section，以及业务 Button、Alert、Message、Tag、Popover。
- 核心功能：未查询时保留已提交结果；必填为空阻止查询；加载时按钮禁用、内容遮罩和转圈；完成时提示「数据已更新」。
- 交互闭环：修改条件 → 变更提示 → 查询校验 → 加载 → 结果更新；校验失败时保留结果并定位空选字段。
- 五项映射已通过。静态文档沿用已有原生导航，预览沿用应用已安装组件与真实 API；用户要求的既有加载样式优先于通用骨架屏建议。

## 实现约束
- 交互事实来源为 src/pages/AnalysisPage.tsx、analysisUI.tsx 和 analysis.css。
- 变更提示位于筛选容器外、下方内容区上方；收起摘要只展示已查询条件。
- 预览以成本定价筛选为例，提供正常修改、清空大区、清空收入售卖区域、清空计费类别、清空计费单元、TOS 不适用及加载样式场景。
- 加载演示持续 2 秒以便观察，说明这是演示时长；加载展示场景保持加载态以便查看样式。
- 直接导入既有内容加载 CSS；不另造遮罩或 spinner。
- 选项 null 表示全部，不视为未选；空数组且字段必填时校验失败；目标值对比可为空；TOS 收入售卖区域禁用且不参与必填校验。
- 说明页通过 iframe 加载独立预览，正式构建和静态发布路径均包含预览入口。

## 验收
- 新 Tab 与 hash 直达正常，既有 Tab 可继续切换。
- 修改条件后摘要和下方结果不变；成功查询后同步更新。
- 空选场景点击查询出现错误 Message，大区/售卖区域显示既有内联错误样式。
- 加载时按钮 loading 且禁用，各内容模块显示半透明遮罩与蓝色转圈；完成后提示成功。
- 检查构建、发布资源、浏览器控制台及窄屏展示。

## 目标值选择补充契约
- 沿用已通过的详情页、模块、组件映射；新增目标影响说明表及复用 AnalysisChart 的两个对照图。模块与组件 API 来自当前业务实现。
- 目标选择属于待查询条件，查询完成才更新目标列、目标线、目标卡片与拓扑节点。允许多选及不对比；实际值不因目标选择改变。
- 收支分析的商品月趋势及明细月趋势只支持月度/季度线；类别整体月趋势支持月度/季度/年度线，年度金额目标使用整年目标，不按月摊分。
- 成本定价单价目标差距按所选周期显示对应图表；不选目标时显示月度测算单价和年度累计测算单价趋势。公式指标月趋势支持三个周期，年度线为点状虚线。
- 收支明细年度列包含累计实际及年度占比/偏差；成本定价的年度累计实际列始终保留。
- 商品概览的年度选择控制年度累计单价偏差柱图，年度价差表仍保留；概览经营现状图不增加目标线。
- 演示使用明确标识的收入示例数据展示动态目标列、商品月趋势无年度线、类别月趋势有年度线。两个图与示例表使用 applied.targets。
