# 拓扑图交互说明预览

## 规范映射清单

- 页面框架命中：沿用交互说明详情页标题、章节导航和内容区。
- 模块命中：在现有拓扑图章节增加完整可操作预览。
- 组件命中：直接复用 PricingTab 的公式模块、FormulaCanvas、TopologyCanvasShell 及全部节点组件。
- 核心功能命中：与业务页面使用相同的数据、解析、布局、样式和趋势。
- 交互闭环命中：节点展开与收起、滚轮缩放、拖拽平移、缩放控制器、适配、截断内容悬浮提示、指标趋势。

## 实现契约

- PricingTab 新增可选 topologyOnly 属性，仅跳过单价目标差距模块，默认业务行为保持现状。
- 独立入口使用共享 defaultFilters，默认展示 bytegraph.cpu / ap / ap-1 与全部目标值；初始节点全部收起。
- 预览顶部复用 VE-O Checkbox，提供月度目标、季度目标、年度目标三个独立勾选项，默认全选，允许全部取消。
- 勾选状态传入共享 filters.targets，控制全部指标节点对应的目标值、偏差行及卡片高度；切换目标保留展开状态。
- 新增模型示例选择，默认展示 RocketMQ 商品定价模型 v1，可切回 Bytegraph。
- RocketMQ 模型来源：model_id=259、version=1、record_type=history；从详情页完整 graphData 提取 26 个独立指标及子项顺序，按分支还原 48 个指标实例、6 层深度。
- RocketMQ 公式与依赖关系按源数据保存于 rocketmq-model-259.ts，保留 sum 函数、括号和重复指标引用；分支实例使用完整路径作为 ID。
- 实际值和单位为构造示例，计算指标使用解析后的源公式推导；目标为固定示例系数生成，偏差实时计算。月趋势使用示例数据。
- 预览载入相同 VE-O 主题、全局字体与分析页面样式；仅移除宿主页面的负边距和外侧 padding。
- 纵向 smoothstep 连线使用 #D0D9E5、2px、borderRadius 16。
- 横向 straight 连线使用 #D0D9E5、1.5px、4 4 虚线；箭头保持共享组件定义。
- 预览打包为独立 HTML、JS、CSS 与本地资源，通过相对地址 iframe 嵌入说明页，不依赖业务服务运行。
- 预览视口高度 760px，宽度撑满说明页内容区；内部保持实际组件尺寸，支持滚动查看趋势。
- 原有章节切换与节点类型说明保留；连线关系说明同步为父指标连接直接表达式项，运算符不生成纵向连线。

## 验收

- 初始根节点与业务页面数据一致。
- 展开根节点后显示四个指标、两个括号表达式与运算符、常量。
- 展开子指标后重新适配，收起根节点后隐藏全部后代。
- 缩放、平移、适配与月趋势均可操作。
- 三种目标可独立勾选；全部取消后仅保留实际值和单位；已展开节点不因目标切换而收起。
- 桌面、窄屏不产生页面级横向溢出；加载资源无错误。
