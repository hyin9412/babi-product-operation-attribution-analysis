# 收支分析复杂指标卡片设计契约

## 页面架构结论

- 页面类型：经营分析 Dashboard。
- 影响模块：收支分析中的「商品收支」核心指标卡片。
- 路由、全局筛选与下方趋势图保持不变。

## 规范映射清单

- 页面框架命中：`Dashboard_页面框架.md`。
- 模块命中：Dashboard 内容区中的核心指标卡片模块。
- 组件命中：新增业务组件 `IncomeMetricCard`；卡片边框、字体、分隔线和背景使用源力语义 Token。
- 核心功能命中：主指标、上月与环比、去年同期与同比、按全局筛选条件展示目标信息。
- 交互闭环命中：全局目标筛选变化后，灰色目标区的内容与高度同步更新；年度目标选中时追加累计实际值与年度目标累计占比。

## Figma 对照

- 主卡片节点：`5342:152910`。
- 环比/同比为 0 节点：`5344:153055`。
- 卡片：白底、1px `#EAEDF1` 描边、6px 圆角、16px 内边距、纵向 8px 间距。
- 标题：PingFang SC，14px/22px，500，`#0C0D0E`。
- 主值：Roboto，28px，600；单位为 12px/20px，500，`#737A87`。
- 对比区：12px/20px；同一行的基准值与变化值之间使用 12px 高竖分隔线。
- 目标区：`#FAFBFC` 背景，`6px 8px` 内边距，行间距 4px。

## 数据与状态规则

- 固定展示：标题、当前实际值、上月实际值、环比、去年同期实际值、同比。
- 未选择任何目标：不渲染灰色目标区。
- 选择月度目标：展示「月度目标」和「偏差」。
- 选择季度目标：展示「季度目标」和「偏差」。
- 选择年度目标：所有指标卡片均展示「年度目标」「1月至今累计实际值」「年度目标累计占比」；成本利润率卡片的「年度目标」同一行保留年度偏差。
- 多字段行沿用语义背景色卡片的截断规则：后置字段优先截断；字段内部先截断 value，再截断 label；只有实际截断时 hover 展示全文。
- 月度偏差数值增加虚线下划线，hover 使用源力 Popover 展示「月度偏差 =（当月实际值 - 月度目标值）/ 月度目标值」。
- 年度目标累计占比数值增加虚线下划线，hover 使用源力 Popover 展示「年度目标累计占比 = 1月至当前账期累计实际值 / 全年目标」。
- 当前原型没有有效目标版本时，目标值、偏差和累计占比展示 `-`；累计实际值仍按 1 月至当前账期数据计算。
- 正向变化：红色上升图形与红色数值。
- 负向变化：绿色下降图形与绿色数值。
- 变化值为 0：使用灰色短横线图形和 `0.0` 文案，不使用 Tag。
- 不适用、不可比或缺失：展示灰色短横线 `-`，不渲染趋势图形。

## 布局约束

- 沿用现有核心指标区的 4/2/1 列响应式布局。
- 同一行卡片高度一致，灰色目标区由筛选条件统一决定内容。
- 所有字段保持单行；超出卡片宽度时省略，不允许撑破卡片。
- 卡片内容区不得嵌套额外装饰卡片。
