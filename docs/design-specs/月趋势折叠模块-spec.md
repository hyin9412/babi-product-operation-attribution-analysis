# 月趋势折叠模块样式契约

## 规范映射与范围
- 页面框架：沿用商品经营归因分析 Dashboard 及现有 Tab。
- 模块：收支分析、其成本分析区和成本定价中的「月趋势」。
- 组件：共享 Fold 的 filter 外观，复用全局筛选的 Button、Popover 与源力 IconRight / IconDown。
- 核心功能：默认收起，展开后呈现原有图表。
- 交互闭环：点击左侧箭头展开/收起，悬停提示动作，支持键盘按钮操作和 aria-expanded。
- 用户指定现有全局筛选为视觉参考，其标题样式优先于通用蓝标标题规范。

## 样式定义
- 容器：背景 var(--color-bg-2)，边框 var(--color-border-2)，圆角 4px，内边距 12px 16px。
- 标题行：沿用 filter-heading，左侧 mini square text 图标按钮，间距 4px；标题 14px，继承全局筛选的字重和颜色。
- 图标：收起 IconRight、展开 IconDown，16px，颜色 var(--color-fill-3)。
- 收起时标题行底部间距 0；不显示标签、筛选摘要或右侧展开文字。
- 展开时标题行下方间距 12px，图表内容复用现有网格。
- 不改变其他 Fold 的外观。

## 收入计费单元类别整体月趋势
- 范围：收支分析 Tab 的「计费项收支」下类别整体趋势模块。
- 名称：收入计费单元类别整体月趋势。
- 复用 `Fold appearance="filter"`，标题、箭头、背景、边框及间距与其他月趋势一致。
- 保留该模块原有默认展开状态；左侧按钮可收起或重新展开，图表数据及分类筛选逻辑沿用原实现。

## 验收
- 两个 Tab 的月趋势默认收起，图标、标题和背景与全局筛选一致。
- 展开和收起后状态与图表显隐一致。
- 模块边界与现有内容区域对齐。
