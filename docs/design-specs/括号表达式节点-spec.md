# 括号表达式节点设计契约

## 1. 页面与模块映射

- 页面框架：沿用现有指标公式关系画布，不调整页面导航、筛选、页签或画布交互。
- 改造范围：新增画布内联复合节点 `BracketExpressionNode`。
- 模块类型：公式分组节点，用于表达同一对括号内的计算内容。
- 组件选型：复用项目内 `MetricTopologyNode`、`ConstantTopologyNode`、`CalculationOperatorNode`；函数节点通过 `content` 槽位调用后续函数节点组件；嵌套括号递归调用 `BracketExpressionNode`。

## 2. 结构与样式

- 类型 Tag 的图标与文字通过 `align-items: center` 垂直居中，不给图标添加顶部偏移。
- 最外层节点直接作为虚线内容区，设置 `position: relative`；节点主体宽高由内容、16px 内边距与边框决定。
- 类型标题绝对定位于 `top: -24px; left: 0`，通过 `margin-left: -1px` 补偿主体边框，使 Tag 左侧与内容框外边缘对齐，底部紧贴上边框；灰色背景、上侧 12px 圆角、图标与文字间距 6px、内边距 `2px 16px`；Tag 不参与主体高度或 centerY 计算。
- 内容区使用 Figma `5362:303873`：白色背景、浅色 1px 虚线描边、四角均为 12px 圆角、基础卡片阴影、16px 内边距。仅通过伪元素在左上圆角外侧缺口补上 Tag 灰色 `#ECEDED`，不覆盖圆角虚线描边。
- 内容区所有直接子元素横向排列，以当前行最高节点的垂直中心线（centerY）居中对齐，相邻元素间距固定为 16px；嵌套括号按各自内容行递归计算。
- 内容区含直接子括号表达式或函数节点时，顶部内边距额外增加 24px，从 16px 增至 40px；其他方向保持 16px。每层独立判断，不按子节点数量累加，画布尺寸与内部指标锚点同步更新。
- 内容区不得通过缩小子节点或字体适配容器；较宽公式由画布平移与缩放查看。
- target 锚点位于虚线框顶部正中，`Position.Top`、`type="target"`、`left: 50%`、`top: 0`；父连线通过分组节点 ID 定位。React Flow 使用原生 Handle，现有 SVG 画布使用同坐标契约的锚点。
- 画布 foreignObject 允许内容溢出，避免浮动 Tag 或展开按钮被裁切。

## 3. 内容模型

- `metric`：通过 `content` 传入已有指标节点。
- `constant`：通过 `value` 调用 `ConstantTopologyNode`。
- `operator`：支持 `add`、`subtract`、`multiply`、`divide`，调用 `CalculationOperatorNode`。
- `function`：通过 `content` 调用函数节点组件；括号组件不自行实现函数外观或交互。
- `expression`：通过 `items` 递归渲染新的 `BracketExpressionNode`。
- 同一层不接受括号字符 token；公式需要括号时必须使用 `expression` 再包一层。

## 4. 交互与状态

- 括号表达式自身为纯展示容器，不新增点击、展开、拖动或悬浮行为。
- 指标节点、函数节点内部交互保持原组件行为。
- 空数组仍保留括号表达式容器，便于上游表达待配置状态；是否展示空态由业务侧决定。
- 每个内容项必须提供当前表达式内唯一的 `id`，保证递归渲染稳定。

## 5. 规范映射清单

- 页面框架命中：指标公式关系画布。
- 模块命中：公式分组复合节点。
- 组件命中：现有指标、常量、运算符节点；函数节点注入；括号节点递归。
- 核心功能命中：四则运算、多指标、常量、函数、嵌套括号。
- 交互闭环命中：子组件交互保留、结构化递归、可访问分组语义。

## 6. 验收清单

- 内容区直接子元素间距均为 16px。
- 常量和四类运算符均复用现有组件。
- 多个指标、常量、函数可按输入顺序混排。
- 嵌套表达式显示为完整的第二层括号表达式样式。
- 同层公式数据中不出现独立的左括号或右括号字符节点。
- 浏览器控制台无重复 key、无效嵌套或资源加载错误。
