# 图表 Tooltip 点击固定设计契约

## 规范映射清单

- 页面框架：沿用现有经营分析 Dashboard。
- 模块：所有使用 AnalysisChart 的图表 Tooltip。
- 组件：复用 VChart 悬停触发、公开 showTooltip(alwaysShow) 与 hideTooltip 接口。
- 核心功能：点击图表固定 Tooltip 内容与位置，固定后支持上下滚动。
- 交互闭环：再次点击图表解除固定，恢复悬停查看。

## 交互与布局

- 悬停图表时展示当前数据；点击图表固定当前点击位置的数据。
- 固定时移出图表、进入或离开 Tooltip 均不会使其消失。
- 点击图表和 Tooltip 以外的空白处解除固定并关闭 Tooltip；点击 Tooltip 内部不解除固定。
- 浮层容器以视口定位，避免长页面滚动后 Tooltip 被定位到视口之外。
- 关闭浮层位移动画，点击后即时停稳。
- 内容区最大高度为 280px，低视口时限制为视口高度减 100px。
- 标题保留在内容区外，系列标记、Label、值一起滚动，滚动不带动页面。
- 取消默认 20 行截断，完整展示当前维度下的全部系列。
- 保留已有金额缩写、虚线图例和峰值 Tag。
- 使用公开接口固定和解除，关闭 enterable 的额外离开事件，使用 CSS 开放 Tooltip 鼠标交互，避免离开 Tooltip 时误关闭已固定内容。
