# 拓扑图间距交互说明

- 框架：沿用交互说明详情页与图表章节的左右结构；左侧真实组件画布，右侧编号说明和实时尺寸。窄屏上下排列。
- 模块：场景选择、目标行数、标注开关、真实拓扑预览、编号间距清单、测量口径说明。
- 组件：复用源力 Select、Checkbox、Button、FormulaCanvas 和方案三；不制作独立假卡片。测量线与子树包围盒仅在说明示例叠加。
- 场景：普通指标、单指标函数、常量括号、双层函数公式、相邻兄弟展开、不同宽度子树展开。
- 尺寸取实际 DOM；按画布缩放比例换算原始 px。区别可见节点边界、完整子树包围盒、父卡片底边与下层外框、展开圆形与下层间距、容器白层及指标内部留白。
- 显示数字编号、双向尺寸线、实时数值、可选子树包围盒；切换场景、目标数量、展开收起、缩放平移后同步测量。
- 使用 topology-flow-preview.html?example=spacing 嵌入拓扑章节，保留原模型预览；源文档 public/docs 与 docs/docs 同步更新。
- 嵌入示例高度随实际内容自适应，移除编号说明与下方规则之间的多余空白；切换场景、窗口宽度变化时同步高度。
- 实际模型示例同样按内容高度自适应，移除 section 底部固定iframe高度造成的多余空白。
- 章节标题为“拓扑图 Playground”，标题旁显示“Figma样式”链接，使用用户提供的设计节点链接并在新标签页打开。
- 右侧“拓扑图整体尺寸”依次标注：拓扑图容器宽度、容器标题行高度、画布可视区域宽度、画布可视区域高度。复用红色尺寸线、编号与点击聚焦说明。
- 容器与画布宽度均为页面内容区宽度；容器标题行固定48px（含底部分隔线）；实际容器高度为屏幕高度−300px，画布可视高度再扣48px，即calc(100vh - 348px)。动态宽高只显示计算规则，不显示最终像素值。示例保持560px预览高度，避免iframe高度反馈循环。
- 整体标线及包围框对应实际容器、标题行与画布视口边界；局部间距继续按100%节点尺寸计量。
- 左右布局（窗口宽度大于1000px）以左侧拓扑图区域的实际高度确定行高；右侧说明区等高，内容超出时仅右侧纵向滚动，不撑高示例。上下布局恢复说明区自然高度。
- 移除拓扑图画布下方的说明条及分隔线；尺寸规则由右侧编号说明与章节规则表承载。
- Playground示例下方、规则表上方的说明段落，上下外间距均为20px。
- 本次规范映射自检：详情页框架沿用；拓扑预览与说明模块沿用；FormulaCanvas、编号按钮及文本组件沿用；核心功能为等高与溢出滚动；交互闭环包括滚动到底、编号聚焦与跨断点恢复自然高度。按用户指定的左右结构作为业务补充规则。
