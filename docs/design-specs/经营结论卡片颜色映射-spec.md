# 经营结论卡片颜色映射

## 页面整体架构
- 对应普通版与拓扑版《商品经营结论卡片与状态 Tag 交互说明》。
- 框架映射：详情展示的标题区与内容区，沿用现有静态说明页。

## 模块与组件映射
- 模块：卡片语义与颜色映射、四张卡片生成规则、场景预览。
- 组件：复用现有语义卡片与原生 HTML 说明表格。
- 核心功能：移除黄色卡片映射及浅黄渐变样式；灰色 `neutral` 场景包含“趋势待补”。
- 交互闭环：不足两期可比利润时，目标差距趋势显示“趋势待补”，场景切换后使用现有灰色卡片样式。
- 用户指定的颜色调整优先于通用规范；此次规则仅针对结论卡片。

## 验收约束
- 普通版与拓扑版的映射、文字规则和场景预览一致。
- 所有“趋势待补”卡片使用 `neutral`。
- 黄色卡片映射、样式和预览引用均移除。
