# 图表全局目标联动

- 目标图表与已提交的全局筛选联动；修改筛选后点击“查询”生效，待查询时保留上次结果。
- 成本定价的单价月趋势按月度、季度、年度独立显隐；取消对应目标时移除整张图及附属说明，网格顺序填充，不保留空位。
- 未选择任何目标时隐藏单价目标月趋势折叠模块，后续定价公式模块上提。
- 公式指标实际值趋势持续展示，目标线与图例按全局选择增删，使用对应目标字段的真实数值。
- 公式指标偏差趋势按月度、季度、年度分成独立图表，展示对应明细中的偏差百分比，仅渲染选中的周期。
- 概览年度累计单价偏差图仅在年度目标选中时展示。

## 保留的特殊规则

- 商品收支四张趋势图遵循[商品收支图表目标线设计契约](./商品收支图表目标线-spec.md)：实际值图持续展示，月度和季度目标线联动，年度目标不生成目标线。
- 单价季度目标图保留“展示各组合月度测算单价与对应季度基准目标。”说明。
- 单价月趋势保留“各组合分别展示，按图例点击显隐；不同计费单位不汇总。”说明。
- 公式指标保留“月度、季度和年度目标来自原型目标版本 V1；单价和比率目标不进行跨月求和。”说明。
- 成本、实际收支等不含目标的图表继续按原有数据范围展示。

## 验证

- 本机 Chrome 验证目标选择的全部 8 种组合。
- 通过全局筛选取消全部目标并查询，验证提交前结果保留、提交后图表隐藏及模块上提。
- 验证 TOS 全选与取消、商品收支特殊目标线规则、概览年度偏差图显隐，无页面运行时错误。
