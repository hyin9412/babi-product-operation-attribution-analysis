# 收支分析数据明细与月度趋势设计契约

## 规范映射与自检
- 页面框架命中：Dashboard，沿用透明化分析现有布局、筛选和图表样式。
- 模块命中：收支明细、计费项成本提供视图切换；收入计费单元类别整体恢复独立月趋势 Fold，显示所有已选类别。
- 组件命中：SourceTable、AnalysisChart、源力 `@tod-m/materials/ve-o` Tabs、Select、Button、Tooltip，以及源力 iconBox 的 IconDataTable / IconLineChart；图标使用 `currentColor` 跟随 Tab 默认、hover 和激活颜色。
- 核心功能命中：Figma `5353:208149` 的 L3 三级“数据明细 / 月度趋势”切换；每张图标题行右侧设置固定选项 Top N。
- 「数据明细 / 月度趋势」直接使用源力 Tabs 的 `type="text"`、`size="small"`、`headerPadding={false}`，开启 16px 表格/折线图图标，不手写覆盖组件的选中、hover、焦点和分隔线样式。
- 当前源力版本的 `text` type 不响应 size 高度，局部仅约束 Tab 项为 32px；颜色、字重、hover、焦点和分隔线继续使用组件原生样式。图标与文字间距 4px。
- 收支分析的「收支明细」「计费项成本」标题使用 `@body-3 medium`（14px/22px、500），与对应 L3 Tab 同行且相邻排列；通过 Tabs.renderTabHeader 复用源力选项卡头部。标题与 Tab 横向间距 16px，标题行与内容垂直间距 12px。
- 定价分析「单价目标差距」标题与右侧 L3 Tab 同样保持 16px 横向间距，不叠加页面级 gap。
- 标题行到首个内容（表格或图表）统一为 12px，趋势图网格不得叠加全局 `margin-top`。
- 月度趋势存在具体计费项筛选时，将“当前查看：{计费项信息} / 清空筛选”提示移至 Tabs 右侧 16px。提示复用源力 Alert 与 Mini Text Button，使用 32px 高度、5px 8px 内边距、64px 圆角、`@primary-1` 背景和 16px info-circle-fill；图标、正文和按钮垂直居中，正文与按钮间距 8px，提示条宽度随内容自适应；清空后仍恢复默认 Top 10。
- 交互闭环命中：大盘浏览默认 Top 10 → 独立改 N/全部 → 单行下钻锁定全部图 → 顶部清空筛选 → 全部图重置 Top 10；图例操作独立于展示范围。

## 状态与数据口径
- 直接点击月趋势，默认展示 Top 10，所有载入图例点亮。
- 支持选择 5、10、20、全部，不开启搜索或自定义输入；切换范围重新载入图表并点亮全部载入图例。
- 收支明细显示“偏差Top N”，按各指标口径月的月度目标偏差绝对值降序排列，缺失值置后。
- 计费项成本显示“成本合计Top N”，按口径月行维度成本合计降序排列。N 表示完整表格维度数量，该维度的所有成本商品系列均展示。
- 表格下钻忽略 N，仅载入所选完整行维度；Tab 下方、全部图上方共用一条“当前查看：完整维度”提示栏，右侧显示“清空筛选”文本按钮。各图隐藏 Top N，不重复展示当前筛选或恢复按钮。
- 共用筛选提示栏使用源力 `Alert type="info"`：采用组件原生信息图标、语义背景、边框和间距；右侧清空操作使用无图标文本按钮，不使用自定义静态灰色背景。
- 点击共用筛选栏清空按钮，清除模块所选维度，同时全部图重置 Top 10；筛选栏消失，各图重新显示独立范围下拉框。
- 大盘浏览时修改一张图的 N/全部，仅影响该图；图例排除、恢复、仅展示、分页沿用原实现，有隐藏图例时提供重置图例（下钻模式同样支持）。
- 返回明细数据清除下钻并重置全部图 Top 10；主动进入月趋势同样默认 Top 10。全局或本地数据范围改变后重置为默认 Top 10。
- 有售卖区域时使用计费单元 × 大区 × 售卖区域，无售卖区域时使用计费单元 × 大区。icon 紧邻售卖区域或大区文字，总计行不下钻。
- 表格趋势图标默认使用 `rgb(var(--primary-6))`，hover/focus 使用 `rgb(var(--primary-5))`；Popover 文案统一为“查看该计费项的月度趋势”。
- 成本趋势按完整行 ID 过滤，避免多个单位、大区、售卖区域交叉组合引入额外系列。
- 收入计费单元类别的计费项成本在单行下钻时按成本商品分配颜色，不同成本商品使用不同颜色。
- 计费项成本在直接进入月度趋势或清空筛选回到 Top N 后按计费项分配颜色；同一计费项下的不同成本商品共用该计费项颜色，不同计费项使用不同颜色。
- Top N 数值变化不改变当前排序内计费项的颜色顺序；下钻与大盘状态切换时按对应颜色语义重新建立图表并重置图例隐藏状态。
- 收支明细月度趋势响应全局目标筛选：勾选月度目标值或季度目标值时，各计费项追加对应目标虚线与图例；取消勾选后同步移除。
- 单个计费项时，月度目标虚线与实际值同色，季度目标虚线使用图表第二个颜色；多个计费项时，实际值、月度目标和季度目标均按计费项共用颜色，不同计费项使用不同颜色。
- 收支明细月度趋势的图例按计费项分组排序：同一计费项依次展示实际值、月度目标、季度目标，再展示下一个计费项。
- 月度目标采用各趋势月份的当月目标；季度目标采用各趋势月份所在季度的累计目标，金额指标按季度已覆盖月份数折算为月均值，成本利润率保持季度目标率。
