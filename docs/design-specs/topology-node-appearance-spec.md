# 拓扑节点外观补充规范

- 本规范覆盖此前拓扑节点契约中的阴影要求。
- 指标、括号表达式、函数、常量和运算符节点统一不显示阴影。
- 展开和收起图标不显示 SVG 内置阴影。
- 保留节点尺寸、圆角、边框、排版、高度联动与原有交互。
- 适用于定价公式画布及复用这些组件的拓扑预览。

## 全屏画布适配

- 进入、退出全屏和画布尺寸变化时，按当前可见拓扑内容自动缩放并居中。
- 适配尺寸使用 SVG 的布局宽高，避免弹窗入场缩放动画影响测量结果。
- 保持现有缩放上下限、画布留白和展开层级。

## 全屏查看明细

- 全屏模式点击指标详细数据入口时，直接在全屏画布上方打开详情 Drawer，不退出全屏。
- 抽屉关闭后，保留画布缩放、位置与已展开节点。
- 抽屉显示期间，全屏弹窗暂停焦点锁定与 Esc 关闭；Esc 仅关闭上层抽屉。
- 详情抽屉使用高于全屏弹窗的层级，支持关闭按钮及遮罩关闭。

## 节点悬浮与点击区域

- 悬浮指标名称显示 Popover，包含完整名称及提示“调用统一的指标解释卡片”。
- 公式保留两行高度，仅溢出时悬浮显示完整公式。
- 偏差数值悬浮显示已有偏差计算公式 Popover；未提供公式时展示对应目标偏差文本。
- 指标名称、溢出的公式和偏差数值等可悬浮提示区域使用手形光标；其余非操作区域使用普通箭头光标。
- 月趋势、展开/收起按钮与多行详情入口使用手形光标。
- 多行数据节点公式下方整个数值区域均为详情按钮，支持鼠标点击与键盘操作，保持区域高度和文案布局。
- 详情文案中“点击”二字默认使用 `rgb(var(--primary-6))`，悬浮详情区域时使用 `rgb(var(--primary-5))`，不加下划线。
