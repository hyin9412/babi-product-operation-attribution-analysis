# 成本定价：未选择目标值时的单价趋势

## 规范映射
- 页面框架：沿用成本定价 Tab 的 Dashboard 布局。
- 模块：单价目标差距表格与趋势切换，沿用表格模块默认分页、排序及维度跳转。
- 组件：复用 TableTrendView、TrendDrillIcon、AnalysisChart、TrendRangeControl。
- 核心功能：目标值全未选中时，显示「月度测算单价趋势」「年度累计测算单价趋势」。
- 交互闭环：趋势 Tab 可切换；表格维度行趋势图标可跳转至该对象的两张趋势图；清空对象后恢复排行。

## 数据与呈现
- 无目标时只展示测算单价实际序列，不生成目标单价及偏差序列。
- 月度实际值复用 normalizedPrice；年度累计实际值复用 cumulativePrice。
- 同维度多个记录沿用 weightedPrice 的计量加权口径。
- 无目标时排行按对应测算单价，默认 Top 5，支持 Top 10、Top 20、全部。
- 选中目标时沿用现有目标对比趋势与偏差排行。
- ByteGraph 维度为计费单元、大区、售卖区域；TOS 维度为计费单元、大区。

## 验证
- 未选目标时趋势切换及行跳转均可用，两张图含实际值且无目标或偏差序列。
- 选回目标后展示对应目标对比趋势，切换全局筛选重置当前对象。
- 沿用现有组件样式、图例、单位与空值处理。
