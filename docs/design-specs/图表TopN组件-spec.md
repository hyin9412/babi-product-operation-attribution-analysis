# 图表 Top N 组件替换契约

- 页面框架：沿用透明化分析页面的图表布局。
- 模块：收入、成本、单价图表右上角的排名范围控制。
- 共享入口：`src/pages/TableTrendView.tsx` 的 `TrendRangeControl`。
- 前缀：统一为“实际值”，不带冒号。
- 排名：按所选账期对应指标的实际值降序取 Top N，不取偏差或绝对值；单价月度、季度目标趋势按月度测算单价排名，年度趋势按累计测算单价排名。成本图继续按实际成本合计排名。空值排在有效值之后。
- 目标组件：BABI 可视化分析页面 DOM 确认为 Arco `InputNumber`，`size="small"`，宽 70px、高 28px，圆角 6px，文字 13px，内边距 12px，带默认的悬停增减按钮。
- 组件来源：用户提供的 BABI 可视化分析页面（`/finance/sell/analysis/`，看板 33、页签 36）；复用相同基础组件，未取得业务封装源码。
- 数值范围：页面输入框 ARIA 属性为最小值 1、最大值 2147483647，整数。
- 默认值：保持 Top 5；输入框显示 `5`。
- Hover 提示：悬停 Top N 输入框时，使用共享 `AnalysisPopover` 展示“选择TopN”。
- 交互闭环：输入时保留草稿，失焦或回车提交有效整数，避免每次按键重建图表而丢失焦点；对接现有 `range`、`onChange` 和排名数据处理，覆盖全部共享控件调用方；单对象钻取时继续隐藏排名范围控件。
- 规范映射自检：页面框架、图表模块、基础组件及真实 API、排名功能和钻取行为已确认。用户指定 BABI 组件优先于 TOD 通用选型。
