卡片语义与颜色映射

语义 tone 使用场景 渐变背景

四张卡片生成规则

1. 经营状态

利润 >= 0 展示「整体盈利」并用绿色；利润 < 0 展示「整体亏损」并用红色；无可比成本展示「暂无可比成本」并用灰色。下方利润金额、成本利润率属于补充字段。

2. 主要风险

存在亏损大区时展示「N 个亏损大区」并用红色，下方展示前 3 个大区名；无亏损大区时展示「版本与公式待核验」并用灰色。

3. 目标差距趋势

对比最近两期利润月度偏差，按 +/-0.5pct 判定「目标差距收窄 / 扩大 / 持平」；不足两期展示「趋势待补」，使用灰色卡片（neutral）。下方只要含数值，比如「最近一期利润月度偏差 -24.34%」，就按补充字段样式。

4. 动作边界

固定展示「暂不直接调价」，蓝色卡片。下方策略文案是单句补充说明，不拆字段。

表格总计行

场景位置与滚动合并规则
存在总计信息的表格 总计行放在表头下第一行并固定为 40px 高（39px 内容＋1px 底边）；纵向滚动时与表头固定；横向滚动时与表头、表体同步且不单独展示滚动条，固定列规则保持一致；禁止总计容器使用负 margin-bottom；所有自定义描边统一使用源力 @color-border-2，且不得形成双线或遮挡第一条数据。 维度列合并展示“总计”，“总计”字号和颜色与表体 Text 类型单元格一致（13px、color-text-1）；连续且无可汇总信息的列合并展示“—”或明确的不汇总原因；可汇总数值逐列展示并右对齐；表体与总计行单元格统一使用常规字重，不加粗。

图表样式配置来源

折线图常态默认不展示数据点，hover 时展示 10 × 10px 圆点和竖向辅助线；辅助线默认颜色 #C9CDD4、实线、1px。柱状图不使用折线辅助线，hover 保留原有矩形背景色块。相关参数分别在“数据点”和“折线图 · Hover 辅助线”分组配置。

总结信息与更多信息仅定义样式，默认均不展示；实际文案、标签内容及数量由应用场景提供，Playground 使用通用示例。该区域距标题默认 8px；在“标题补充”分组分别开关。按 Figma 5341:150584，总结为 13px / 22px，两行间距 4px；更多信息采用 12px / 20px、4px 圆角、左右内边距 6px 的灰底标签。总结、更多信息、标题和单位合并为标题区域整体，到绘图区的间距保持固定。

图例与 Tooltip 的标记均可独立选择方块或虚线，默认方块，两处方块圆角固定为 1.54px。图例在“图例外观”中配置，Tooltip 在“Tooltip 面板”中配置；虚线宽度可分别调整，标记沿用对应系列配色。

Tooltip 的“金额自动缩写”默认开启：金额绝对值达到 1 万时按万展示，达到 1 亿时按亿展示，统一保留 2 位小数并保留负号；不足 1 万保持原数值。该规则应用于归因分析页所有人民币、CNY 或元类图表，百分比、计费单位数量等非金额图表不缩写。

图例默认左对齐，每页最多展示 2 行；可配置左对齐、居中或右对齐，以及每页最多行数。超出时在右侧显示上下翻页按钮和页码。调整宽度、间距或系列数会自动重新分页，翻页保留系列筛选状态与配色。

图例交互的“背景与宽度”分组统一配置悬停背景颜色、高度、圆角和宽度模式。默认宽度随色块＋文字自适应，背景左右内边距各 4px；超过自适应最大宽度时省略文字。后方“仅展示”图标独立计算尺寸和间距。

标题与单位作为一个整体：内部保留“标题 → 单位”间距，外部统一设置“标题与单位整体 → 绘图区”间距。隐藏单位时，整体仅剩标题，外部间距保持不变。

绘图区支持固定高度或按卡片剩余空间自适应。自适应模式使用整体卡片高度，扣除上下边框、内边距、标题、可选单位、图例实际高度及对应间距；图例换行和单位隐藏会自动重新分配绘图区高度。

图表空态

Playground 顶部勾选“图表空态预览”即可查看统一空态。保留标题、单位及尺寸配置，隐藏图例与 Tooltip；关闭后恢复原图例筛选和分页状态。自适应模式将隐藏图例后释放的空间分配给空态绘图区。

项目 展示与交互规则
触发条件 图表数据为空，或所有数据点的 value 均为 null。
保留内容 保留图表卡片、标题与已配置的单位信息；单位信息字号为 12px。
空态图标 使用 IconBox 的 IconEmptyChart，尺寸为 80 × 80px。
空态文案 暂无可用数据。字号为 13px，行高为 22px，使用次要文本色。
位置与间距 图标与文案整体在绘图区水平、垂直居中，图标与文案间距为 8px。
绘图区高度 保持图表配置的高度，默认 250px，不因空态收缩。
图表元素 空态不渲染 VChart、坐标轴、数据图形、图例或 tooltip。
边界情况 数值为 0 时正常绘图；仅部分数据点为 null 时，过滤这些点后绘制其余数据。手动隐藏全部图例不触发数据空态。
